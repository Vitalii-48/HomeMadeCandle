# Jira QA Template

Цей шаблон допомагає швидко оформлювати задачі на перевірку і баги в `Jira`.

## 1. Шаблон задачі на ручне тестування

**Summary**

```text
QA: Manual regression check for cart and checkout
```

**Description**

```text
Потрібно провести ручну перевірку основних сценаріїв після змін у проєкті.

Що перевірити:
- головна сторінка
- каталог
- сторінка товару
- сторінка композицій
- кошик
- checkout
- сторінка успішного замовлення

Очікування:
- базові сторінки відкриваються без помилок
- товари та композиції додаються в кошик
- лічильник кошика оновлюється
- checkout створює замовлення
```

**Suggested labels**

```text
qa
manual-testing
regression
```

## 2. Шаблон баг-репорту в Jira

**Summary**

```text
[Bug] Cart badge does not update after adding product
```

**Description**

```text
Короткий опис:
Після додавання товару в кошик показується повідомлення про успішне додавання, але лічильник кошика не оновлюється одразу.

Кроки для відтворення:
1. Відкрити каталог
2. Натиснути "Додати в кошик" на будь-якому товарі
3. Подивитися на лічильник біля іконки кошика

Очікуваний результат:
Лічильник кошика одразу збільшується.

Фактичний результат:
Лічильник не змінюється до оновлення сторінки або переходу на іншу сторінку.

Середовище:
- Local
- Windows
- Browser: Chrome
```

## 3. Які поля корисно заповнювати в Jira

- `Summary`
- `Description`
- `Priority`
- `Labels`
- `Assignee`
- `Environment`
- `Attachment` або скріншот

## 4. Рекомендовані типи задач

- `Task` — якщо це задача на перевірку
- `Bug` — якщо знайдена помилка
- `Story` — якщо велика функція і до неї додається тестування

## 5. Простий процес роботи

1. Зміни в коді завершені.
2. Запущені автотести.
3. Створюється задача на ручну перевірку або проходиться існуючий чекліст.
4. Якщо знайдено проблему, створюється `Bug`.
5. Після виправлення багу перевірка повторюється.
