# Google Sheets QA Template

Нижче шаблон таблиці для `Google Sheets`.
Просто створи нову таблицю і скопіюй туди ці колонки.

## Варіант колонок

```text
ID,Модуль,Сценарій,Кроки,Очікуваний результат,Фактичний результат,Статус,Пріоритет,Коментар,Дата,Перевірив
```

## Як користуватись таблицею

- `Not Run` — ще не перевіряли
- `Passed` — все працює
- `Failed` — знайдено проблему
- `Blocked` — не можна перевірити через залежність або відсутні дані

## Рекомендовані значення

- `Статус`: `Not Run`, `Passed`, `Failed`, `Blocked`
- `Пріоритет`: `Low`, `Medium`, `High`, `Critical`

## Простий робочий підхід

1. Перед перевіркою копіюєш потрібні рядки в новий лист.
2. Під час тестування змінюєш `Статус`.
3. Якщо є проблема, коротко описуєш її в `Коментар`.
4. Якщо баг важливий, переносиш його в `Jira`.
