# Manual Test Checklist

Цей документ потрібен для простої ручної перевірки сайту після змін у коді.
Його зручно відкривати перед комітом або після змін у кошику, checkout, UI чи адмінці.

## Як користуватись

1. Запусти автотести.
2. Якщо автотести пройшли, відкрий сайт у браузері.
3. Пройди короткий ручний чекліст нижче.
4. Якщо знаходиш проблему, занеси її в баг-трекер або список задач.

## Швидка перевірка перед комітом

- [ ] Сайт запускається без помилок
- [ ] Головна сторінка відкривається
- [ ] Каталог відкривається
- [ ] Товар додається в кошик
- [ ] Композиція додається в кошик
- [ ] Лічильник кошика оновлюється одразу
- [ ] Кошик відкривається і показує правильні товари
- [ ] Замовлення оформлюється без помилки

## Головна сторінка

- [ ] Головна сторінка відкривається без `500`
- [ ] Видно хедер і меню
- [ ] Показуються товари або композиції
- [ ] Іконка кошика відображається
- [ ] Лічильник кошика показує правильне число

## Каталог

- [ ] Каталог відкривається
- [ ] Картки товарів показуються коректно
- [ ] Видно назву і ціну
- [ ] Працює кнопка додавання в кошик
- [ ] Після додавання з'являється повідомлення
- [ ] Лічильник кошика змінюється без перезавантаження

## Сторінка товару

- [ ] Сторінка товару відкривається
- [ ] Фото товару відображаються
- [ ] Опис і характеристики видно
- [ ] Вибір кольору працює
- [ ] При зміні кольору ціна оновлюється правильно
- [ ] Кнопка `Додати в кошик` працює
- [ ] Після додавання показується повідомлення
- [ ] Після додавання лічильник кошика оновлюється

## Сторінка композицій

- [ ] Сторінка композицій відкривається
- [ ] Картки композицій показуються
- [ ] Додавання композиції в кошик працює
- [ ] Після додавання з'являється повідомлення
- [ ] Лічильник кошика оновлюється

## Кошик

- [ ] Сторінка кошика відкривається
- [ ] Додані товари видно у списку
- [ ] Додані композиції видно у списку
- [ ] Зміна кількості працює
- [ ] Сума перераховується правильно
- [ ] Видалення позиції працює
- [ ] Порожній кошик відображається коректно

## Checkout

- [ ] Сторінка checkout відкривається
- [ ] Поля форми видно
- [ ] Можна ввести ім'я і телефон
- [ ] Можна вибрати спосіб зв'язку
- [ ] Можна вибрати спосіб доставки
- [ ] Для `Нова Пошта` можна вибрати місто
- [ ] Для `Нова Пошта` можна вибрати відділення
- [ ] Для `Самовивіз` поля Нової Пошти не заважають
- [ ] Після оформлення відкривається сторінка успіху
- [ ] Після оформлення кошик очищається

## Сторінка успішного замовлення

- [ ] Відкривається без помилки
- [ ] Показується номер замовлення
- [ ] Є повідомлення для користувача
- [ ] Є кнопка повернення в каталог або на головну

## Адмінка

- [ ] Відкривається логін-сторінка
- [ ] Успішний вхід працює
- [ ] Відкривається список товарів
- [ ] Відкривається список композицій
- [ ] Відкривається список замовлень
- [ ] Відкривається форма редагування товару
- [ ] Відкривається форма редагування композиції

## Якщо знайдено проблему

Зафіксуй мінімум таке:

- де саме виникла проблема
- які кроки виконувались
- який був очікуваний результат
- який був фактичний результат
- чи повторюється проблема ще раз
